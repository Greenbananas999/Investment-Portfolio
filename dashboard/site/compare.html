What these terms mean
Sharpe ratio
Return earned above the T-bill rate for each unit of volatility (ups and downs). Higher is better; 0.5 is decent, 1.0 is strong.
Information ratio
How much a holding beat its benchmark per unit of the risk it took by differing from it (active return divided by tracking error). Above 0.5 is good, but it needs a t-statistic above about 2 to be believable.
Max drawdown
The worst peak-to-trough fall in month-end value. A -25% drawdown turns $100 into $75 before it recovers.
Rolling 36-month
A measure recalculated every month over the latest 36 months. It shows whether an edge is steady or came from one stretch.
Local vs USD return
Return in the asset's home currency compared with the dollar return the US investor gets. The difference is the currency effect.
In-sample (IS)
The 2010-2017 data that every screen and shortlist was built from. Good in-sample numbers say little about the future, so they sit beside the out-of-sample ones to show how much held up.
Out-of-sample (OOS)
Data the selection never saw. Here: Jan 2018 to Oct 2026, with every screen built only from data up to Dec 2017.
Deflated Sharpe
The probability that the Sharpe ratio is real after allowing for how many candidates were tried. Test dozens of names and the best one looks good by luck; 0.95 or more is convincing, below 0.5 is a coin flip.
